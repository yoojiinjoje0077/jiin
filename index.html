01 / 문제

도구는 바뀌는데, 강의는 바로 바꾸기 어려웠어요.

AI 도구의 기능과 UI가 빠르게 바뀌는 반면, 국비지원 교육 콘텐츠는 변경 심사 절차가 필요했습니다. 근무를 시작하고 3개월 동안 업데이트 관련 문의가 30건 이상 발생했고, 운영자는 문의가 올 때마다 여러 도구를 직접 검색해야 했습니다.

02 / 판단

반복 문의를 콘텐츠 최신성의 문제로 정의했습니다. 학습에 영향을 주는 변경 사항을 미리 수집하고 안내를 준비하는 구조를 설계했습니다.

기존 대응문의 발생 후 직접 검색 및 교안 제작

01 / 문제

규정의 순서와 고객의 실제 행동이 달랐어요.

고용24 신청 후 자비부담금을 결제하는 것이 원칙이었지만, 회사 홈페이지에서 먼저 결제하는 고객이 많았습니다. 외부 기준도 충분히 명확하지 않아 상담자별 안내 차이와 고객 오인지 가능성이 있었습니다.

02 / 선택·근거

하나의 원칙만으로 설명할 수 없는 고객도 있었어요.

반복 문의와 혼선 지점을 수집하고 관련 규정을 확인했습니다. 규정상의 순서와 실제 고객 유입 여정을 비교한 뒤, 팀 논의로 ‘고용24 신청 → 자비부담금 결제’를 기본 안내로 정했습니다. 이미 결제한 고객을 위한 예외 절차도 마련했습니다.

03 / 기여·결과

결정된 기준을 고객이 읽는 모든 안내에 반영했어요.

저는 문제 구조화, 규정 확인, 수강 가이드와 문자 템플릿 적용을 맡았습니다. 기본 원칙과 예외 처리를 함께 남겨 일관된 상담의 기반을 마련했습니다.

기여와 측정의 범위기준은 팀 논의로 결정했습니다. 템플릿 변경 전후의 반복 문의 비율은 추가 측정이 필요합니다.
