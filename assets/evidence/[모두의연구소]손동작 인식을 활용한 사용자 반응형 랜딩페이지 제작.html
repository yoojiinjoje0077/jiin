🐱 손동작으로
고양이 쓰다듬는
랜딩페이지 만들기

코드를 몰라도 괜찮아요. AI에게 말로 설명하고 함께 완성합니다.

준비물: 노트북 + 웹캠 + 인터넷 (키보드의 방향키로 페이지를 넘겨주세요.)

※ 본 교안에 대한 별도의 학습 문의는 진행하지 않습니다.

Preview

오늘 우리가 만드는 것

Live Demo

웹캠 앞에서 손을 좌우로 쓰다듬는 동작을 하면, 화면 속 고양이가 눈을 감고 골골골 행복해하는 인터랙티브 랜딩페이지예요.

손 인식 → 동작 판정 → 화면 반응, 이 세 가지 원리를 프롬프트 몇 번으로 완성합니다.

Concept

바이브 코딩이 뭔가요?

문법을 외우는 대신, "이런 걸 만들어줘"라고 자연어로 설명하면 AI가 코드를 작성해주는 개발 방식이에요.

우리는 완벽한 코드를 짜는 사람이 아니라, AI에게 무엇을 원하는지 명확하게 설명하는 사람이 되면 됩니다.

STEP 0

Setup

작업 전 마음의 준비하기

  • 교안대로 안되거나 모르는 내용이 있다면 AI에게 물어봐주세요.
    AI가 현재 작업 상태를 가장 잘 알고 있습니다.
  • 코드를 전체 수정해주지 않고 부분만 수정해준다면 전체를 수정하여 파일로 만들어 달라고 요청해보세요.
  • 결과물은 index.html 파일 하나로 완성됩니다
STEP 1

Prompt

페이지 뼈대 요청하기

이렇게 말해보세요웹캠으로 손동작을 인식해서 화면이 바뀌는 랜딩페이지를 만들고 싶어. 우선 index.html 파일에 제목, 설명 문구, 고양이가 들어갈 네모난 영역, "카메라 시작하기" 버튼만 있는 기본 뼈대부터 만들어줘.
  • 검은 코드 박스 안의 프롬프트를 드래그하여 AI에게 요청하세요!
  • 활용 단축키(복사 = Ctrl C, 붙여넣기 = Ctrl V)

Check

결과 확인하기

  • index.html을 다운받아 더블클릭해서 브라우저로 열어봐요
  • 만약 파일 생성 없이 코드만 만들어주었다면 코드를 복사하여 메모장에 저장해주세요.
    (저장 시 파일 이름은 'index.html', 파일 형식은 '모든 파일'로 설정 필수)
  • 이렇게 저장한 후 생성한 파일을 열면 지금까지 진행한 부분을 볼 수 있어요!
  • 메모장으로 HTML 파일을 만들기가 어렵다면 AI에게 HTML 파일로 만들어달라고 요청해주세요.
  • 제목과 설명 문구가 보이나요?
  • 네모난 영역과 버튼이 보이나요?
  • 원하는 모습과 다르면 "여기를 이렇게 바꿔줘"라고 다시 요청하면 돼요
STEP 2

Prompt

고양이 캐릭터 그려달라고 하기

이렇게 말해보세요네모 영역 안에 귀여운 고양이 얼굴을 SVG로 그려줘. 눈은 뜬 상태와 감은 상태 두 가지를 만들고, 평소엔 뜬 눈, 나중에 쓰다듬으면 감은 눈으로 바뀌도록 준비해줘.

먼저 요청했던 프롬프트와 같은 채팅창에 위의 프롬프트를 추가 요청해주세요.

Tip

고양이가 이상하게 생겼다면?

AI가 그린 그림이 마음에 안 들어도 괜찮아요. "귀를 더 크게", "눈 색깔을 바꿔줘"처럼 구체적으로 다시 요청해보세요.

한 번에 완벽한 결과를 기대하기보다, 대화하며 조금씩 다듬는 게 바이브 코딩의 핵심이에요.

Concept

손동작 인식은 어떻게 작동할까요?

MediaPipe Hands라는 구글의 무료 도구가 카메라 화면에서 손의 21개 관절 위치를 실시간으로 찾아줘요.

우리는 이 21개 점 중 손바닥 위치가 어떻게 움직이는지만 보면 됩니다.

STEP 3

Prompt

웹캠과 손 인식 연결하기

이렇게 말해보세요"카메라 시작하기" 버튼을 누르면 웹캠을 켜고, MediaPipe Hands 라이브러리로 손을 인식하게 해줘. 화면 오른쪽 아래에 카메라 화면과 인식된 손 관절 점들을 작게 미리보기로 보여줘.

Check

결과 확인하기

  • 버튼을 누르면 카메라 권한 요청 창이 뜨나요? → 허용을 눌러요
  • 화면 구석에 내 손이 비치나요?
  • 손 위에 점과 선(관절)이 그려지나요?
  • 안 되면 현재 컴퓨터 상황을 캡처해서 AI에게 물어보세요

Concept

"쓰다듬는 동작"은 어떻게 판단할까요?

손이 고양이 영역 안에서 왼쪽 → 오른쪽 → 왼쪽처럼 방향을 반복해서 바꾸면, 그걸 쓰다듬는 동작으로 판단해요.

최근 1초 동안 손의 위치를 기록해두고, 방향이 몇 번 바뀌었는지 세는 방식이에요.

STEP 4

Prompt

쓰다듬기 판정 로직 요청하기

이렇게 말해보세요손 위치가 고양이 영역 안에서 좌우로 왔다갔다 하는 걸 감지해서, 방향이 2번 이상 바뀌면 "쓰다듬는 중"이라고 판단하는 로직을 추가해줘. 쓰다듬는 중일 땐 상태 표시 문구도 바꿔줘.
STEP 5

Prompt

고양이 반응 애니메이션 추가하기

이렇게 말해보세요쓰다듬는 중일 때 고양이 눈을 감은 눈으로 바꾸고, 볼에 홍조를 넣고, 하트 이모지가 위로 떠오르는 효과를 추가해줘. 또 애정도 게이지 바를 만들어서 쓰다듬을 때마다 조금씩 채워지게 해줘.

Check

완성본 확인하기

  • 손으로 고양이 위를 좌우로 움직이면 눈이 감기나요?
  • 하트가 떠오르나요?
  • 게이지 바가 채워지나요?
  • 손을 멈추면 원래 표정으로 돌아오나요?

Troubleshooting

자주 만나는 문제들

카메라 권한 거부
브라우저 주소창의 자물쇠 아이콘에서 카메라 권한을 다시 허용해요
라이브러리 로딩 실패
인터넷 연결을 확인하고 새로고침 해봐요
손이 인식 안 됨
조명을 밝게 하고 손 전체가 화면에 보이게 해봐요
화면이 하얗게 나옴
개발자 도구(F12)의 콘솔 에러 메시지를 AI에게 그대로 붙여넣어 물어봐요
