주요 기능 사용법

GPT-5.6 모델 및 자동화 활용 가이드

  1. GPT-5.6 모델 선택: Plus/Pro 사용자는 설정에서 'GPT-5.6 Sol', Free/Go 사용자는 'GPT-5.6 Luna' 모델이 기본으로 적용됩니다. NEW
  2. 'Think' 버튼 활용: 답변이 불확실하거나 더 심층적인 분석이 필요할 때, 답변 하단의 'Think' 버튼을 클릭하여 AI의 사고 과정을 유도하고 개선된 답변을 얻습니다. NEW
  3. 웹훅 기반 자동화 설정: ChatGPT 설정 메뉴에서 'Task Automation'으로 진입하여 Gmail, Slack, GitHub 웹훅을 연결하고, 반복적인 태스크를 스케줄링하여 자동 실행합니다. NEW
  4. Google Drive 연동: 채팅 중 첨부 파일 아이콘을 클릭하여 Google Drive 파일을 직접 연동합니다. 문서, 스프레드시트, 프레젠테이션 파일을 ChatGPT와 사이드 바이 사이드로 작업하며 콘텐츠를 분석하고 생성합니다. NEW
  5. ChatGPT Work 브라우저 사용: 웹사이트 로그인 정보를 저장하고, 복잡한 웹 기반 작업(예: 데이터 입력, 양식 제출)을 ChatGPT에게 지시하여 자동 실행하게 합니다. NEW

새로운 기능, 어디서 찾을 수 있나요?

다음 경로를 따라가면 업데이트된 ChatGPT의 신기능들을 쉽게 발견하고 활용할 수 있습니다.
GPT-5.6 모델 전환: 설정 > 모델 선택 > GPT-5.6 Sol/Luna
'Think' 버튼: 채팅창 > 답변 하단
태스크 자동화: 설정 > Task Automation
Google Drive 연동: 채팅 입력창 > 첨부 파일 아이콘 > Google Drive
Site tools (WebMCP): 설정 > AI Agents > Site tools (WebMCP)
ChatGPT Images (통합): 채팅 입력창 > 이미지 생성/편집 아이콘
macOS 컴퓨터 활동 기록: macOS 앱 > 설정 > Computer History
심화 설정 가이드

AI 에이전트 및 개인화 설정

  1. 'Site tools (WebMCP)' 활성화: `[설정] > [AI Agents] > [Site tools]` 경로에서 웹사이트 접근 권한 및 사용 가능한 도구를 설정하여 AI 에이전트의 활용 범위를 확장합니다. NEW
  2. 임시 채팅 제어: `[새 채팅 시작] > [임시 채팅 옵션]`에서 현재 대화의 저장 여부 및 개인화 학습 적용 범위를 세밀하게 설정하여 개인정보 보호와 편의성을 높입니다. NEW
  3. macOS 컴퓨터 활동 기록 관리: `[macOS 앱] > [설정] > [Computer History]`에서 ChatGPT가 학습할 컴퓨터 활동 기록의 범위와 제외할 앱을 설정하여 개인화된 AI 경험을 만듭니다. NEW
  4. 학술 연구 전용 워크스페이스: `[ChatGPT Work] > [워크스페이스 전환]`을 통해 학술 연구 모드를 활성화하면, 논문 검색 및 요약 기능이 최적화되어 연구 생산성을 크게 향상시킬 수 있습니다. NEW
실용적인 활용법

업데이트된 ChatGPT로 생산성 높이기

  1. 보고서 자동 작성 및 요약: Google Drive에 연동된 보고서 파일을 ChatGPT에게 분석하게 한 후, 초안을 작성하고 요약본을 만들어 웹훅을 통해 관련 팀 Slack 채널에 자동으로 알림을 전송합니다. NEW
  2. 복잡한 온라인 예약 자동화: ChatGPT Work 브라우저를 활용하여 OpenTable, Resy, Yelp 등 연동된 서비스를 통해 원하는 식당을 검색하고 예약하는 전 과정을 ChatGPT가 대신 처리하게 합니다. NEW
  3. 코딩 및 개발 작업 지원: GitHub 웹훅과 연동하여 코드 리뷰를 자동화하고, 특정 조건(예: 버그 발생) 발생 시 Slack으로 즉시 알림을 받거나, GitHub 이슈를 자동 생성하도록 설정합니다. NEW
  4. 개인화된 학습 도구 활용: 대화형 퀴즈 기능을 통해 어떤 학습 콘텐츠든 개인 맞춤형 질문으로 변환하여 능동적인 학습을 유도하고, Linux 데스크톱 앱을 통해 학습 접근성을 확장합니다. NEW
